# 人物相似度与有限色料槽

处理照片人物、用户要求“更像本人”或指定颜色上限时读取。

## 人像迭代

先提取可见的几何关系：脸部长宽、下颌收窄位置、发际线与刘海方向、眼睛相对镜框的大小和位置、鼻口间距、嘴形与表情。衣服颜色和配饰不能替代面部相似度。漫画化也应保留这些关系，避免默认套用大圆脸、大眼睛和微笑。

头部首次成形后先生成真实网格的正面近照，再看三分之四视角和整体比例。对照参考图检查，不满意时先修形再切片。尤其检查发片是否像硬条、嘴唇是否过凸、镜框是否盖住眼睛。渲染和导出必须采用同一几何与配色，不以生成式概念图证明可打印效果。

保留旧版用于比较。相似度属于视觉判断，不能用网格检查、切片成功或虚构的相似度百分比证明；仅一张正面照片时说明侧面和背面的补全。只有确实需要更多视角时才请求补充照片，不把额外照片当作开始工作的前提。

## 颜色预算

用户给出料槽数量后，把它作为当前工程的颜色上限，而不是永久强制所有项目四色。先保留区分人物的关键颜色，再合并次要配饰：例如黑、肤色、衣服主色、浅色中性色。与用户说明牺牲了哪些颜色。

几何部件数不等于耗材数。七个部件可以映射四个逻辑耗材，创建工程时按逻辑槽位去重耗材配置；不能每个部件都追加一卷同色耗材。校验颜色表长度和每个部件的映射，同时确保对象、底座、支撑、擦料塔仍在一盘内。

```text
python scripts/inspect_3mf.py model.3mf --report project-check.json --max-filaments 4
```

该检查要求部件有显式槽位，或其直接父对象有明确记录的可继承槽位；不能凭缺少元数据默认指定槽 1。它也检查三角面涂色树中的耗材号。无法解析的继承或不同格式需在 Studio 中进一步核对。检查归档和映射仍不代表切片或实机 AMS 匹配成功。

四种耗材可在同层多次切换。“一盘、一次任务”不等于“只换色四次”。实际切片后报告总时间、总耗材、换色次数，并包含支撑、擦料塔和冲刷开销。可提供同几何单色试打版，但不擅自用单色替代用户的多色交付。

颜色合并后更新真实几何预览、可编辑场景、工程、切片结果和报告；不要使用旧版预览或旧版估算。现有网格若完全未变可用哈希确认并复用几何检查；几何有改动则重查。
